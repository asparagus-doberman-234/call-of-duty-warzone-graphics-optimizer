# Call of Duty: Warzone Graphics Optimizer — feature reference

Graphics categories, benchmark notes, and preset library form the core of Call of Duty: Warzone Graphics Optimizer. Related configuration is grouped by task rather than collected in an undifferentiated list.

| Section | Description |
|---|---|
| Graphics categories | Display or performance-related options, with space for configuration and comparison information. |
| Benchmark notes | Display or performance-related options, with space for configuration and comparison information. |
| Preset library | Related settings collected into named groups for a clearer configuration workflow. |
